PDF 护眼模式 - 隐私政策

最后更新：2026年5月2日

概述

PDF 护眼模式（以下简称"本扩展"）尊重并保护用户隐私。本扩展不会收集、存储、传输或共享任何用户个人信息。

数据收集

本扩展不收集任何用户数据，包括但不限于：

  • 浏览历史
  • 个人身份信息
  • PDF 文件内容
  • 使用行为数据
  • 设备或浏览器信息

本地存储

本扩展使用 Chrome 提供的 chrome.storage.local API 在用户设备本地存储以下设置：

  • 护眼模式的开关状态
  • 自动启用的开关状态
  • 用户选择的色调模式

这些数据仅保存在用户本地设备上，不会被发送到任何外部服务器，也不会被本扩展读取用于其他目的。

网络通信

本扩展不进行任何网络请求，不连接任何远程服务器，不使用任何第三方服务。

权限说明

  • storage：用于在本地保存用户的护眼设置。
  • host_permissions (<all_urls>)：用于在各类 PDF 页面（包括直接打开、网页内嵌、blob URL 等来源）注入护眼样式。本扩展不会将此权限用于除 PDF 页面样式调整以外的任何用途。

第三方服务

本扩展不集成任何第三方 SDK、分析工具或广告服务。

隐私政策变更

如果本隐私政策有任何更新，将在本页面发布变更内容。

联系方式

如对本隐私政策有任何疑问，请通过本扩展在 Chrome Web Store 的开发者联系方式与我们沟通。
